# Chocó Vanilla Tech

**Plataforma Tecnificada de Curado de Vainilla**  
Proyecto académico orientado al monitoreo climático, trazabilidad de lotes, control de procesos y modelado de dominio aplicado a la cadena de valor de la vainilla en el Chocó Biogeográfico.

## Objetivo del proyecto

Chocó Vanilla Tech propone una solución tecnológica para mejorar el proceso de curado de vainilla mediante herramientas digitales de monitoreo, control y trazabilidad.

El sistema busca representar cómo una planta piloto podría controlar variables críticas del proceso, como temperatura, humedad, estado del lote, etapa de curado y condiciones de operación.

## Diferencia entre ambas versiones

### Coco UI — Enfoque visual y comercial

La versión **Coco UI** está orientada principalmente a la presentación visual del producto.

Su objetivo es mostrar el proyecto como una solución atractiva para un posible cliente, productor, institución o inversor.

Se enfoca en:

- Diseño visual premium.
- Identidad agroindustrial.
- Imágenes temáticas de vainilla, plantación, cámaras y proceso.
- Lectura rápida del producto.
- Impacto visual para exposición.
- Experiencia de usuario clara y elegante.
- Presentación institucional de FreToKa Lab.

Esta versión funciona muy bien para explicar el proyecto de forma simple, mostrar su potencial comercial y transmitir una imagen profesional.

---

### Kanon UI — Enfoque académico, técnico y didáctico

La versión **Kanon UI** está orientada a demostrar la lógica técnica del sistema.

Su objetivo es mostrar cómo el proyecto puede pensarse desde la programación, la arquitectura y el modelado orientado a objetos.

Se enfoca en:

- Simulación operativa de planta.
- Estados del proceso de curado.
- Sensores de temperatura y humedad.
- Actuadores simulados.
- Control de cámara climática.
- Trazabilidad de lotes.
- Modelo de dominio POO.
- API REST simulada.
- Dashboard ejecutivo.
- Explicación académica del funcionamiento interno.

Esta versión es más didáctica y técnica. Sirve especialmente para defender el proyecto ante docentes, explicar decisiones de arquitectura y evidenciar conceptos de Programación Orientada a Objetos.
